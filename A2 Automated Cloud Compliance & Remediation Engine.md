This project moves away from building applications and focuses on Cloud Security Operations.

- The Goal: Create a system that monitors a cloud environment, detects security policy violations, and automatically fixes them (or alerts you).
- DevOps Component: Monitor cloud resource changes using CloudWatch events or EventBridge. Use a serverless function (e.g., AWS Lambda) to execute the "remediation."
- Security Component:
    - Define "Compliance as Code." For example: "If an EC2 instance is launched without encryption, immediately terminate it or encrypt it automatically."
    - Show proof of compliance: Generate a dashboard that shows the current health and security state of your cloud resources.
